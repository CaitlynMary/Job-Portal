# Job Portal Project

This is a **full-stack job portal web application** built using the **MERN stack (MongoDB, Express.js, React.js, Node.js)**. The project also integrates **Clerk** for user authentication and **Sentry** for error tracking and performance monitoring. It provides a complete platform for **job seekers** and **recruiters** to interact seamlessly.

---

## 🚀 Project Overview

✅ **Job Seekers:**
- Search for job openings.
- Apply for jobs online.
- Upload resumes to their profile.
- Secure user authentication using Clerk.

✅ **Recruiters:**
- Post new job openings.
- Manage job posts (visibility, status).
- View applicants and their details.
- Accept or reject job applications.
- Access applicant resumes.

✅ **Admin & Monitoring:**
- Integrated Sentry for error tracking and MongoDB query monitoring.

✅ **Deployment:**
- Deployed using **Vercel** for continuous deployment and seamless updates.

---

## ⚙️ Tech Stack

- **Frontend:** React.js  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB  
- **Authentication:** Clerk  
- **Cloudinary:** Image upload and management  
- **Sentry:** Error tracking & performance monitoring  
- **Deployment:** Vercel  

---

## ✏️ Features

🔹 Full user authentication and authorization system.  
🔹 Recruiter dashboard for job posting and managing applications.  
🔹 Job seeker dashboard for tracking job applications.  
🔹 File upload for resumes (handled using **Multer** & **Cloudinary**).  
🔹 Clean and user-friendly UI.  
🔹 Error tracking and performance monitoring using Sentry.  
🔹 Deployed and live on Vercel.
